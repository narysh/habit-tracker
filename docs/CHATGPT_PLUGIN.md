# Публичный плагин Habit Tracker

Плагин открывает три действия: получить задачи, создать задачу, отметить задачу выполненной. Пользователь подключает свой аккаунт Habit Tracker через OAuth. Созданная задача появляется на телефоне после синхронизации с тем же сервером. Доступ к заметкам, привычкам, вложениям и управлению аккаунтом через публичное подключение закрыт.

## Развёртывание

1. Выделить постоянный HTTPS-домен. Временный адрес демонстрационного туннеля OpenAI не принимает. Настроить TLS-прокси с пересылкой оригинального `Host` и доступом к backend по внутреннему адресу. Следовать [требованиям OpenAI к MCP](https://developers.openai.com/plugins/build/mcp-server), включая mTLS, когда используется публичный прокси перед частным MCP. Сам backend сертификаты клиента не проверяет.
2. Развернуть Ktor и PostgreSQL с постоянными томами для базы и вложений. Настройки есть в `compose.yaml` и `.env.example`: `PUBLIC_URL` равен HTTPS origin, `PUBLIC_CHATGPT_PLUGIN=true`, `BACKEND_BIND=127.0.0.1`. Задать отдельный `MCP_CLIENT_ID=habit-tracker-chatgpt` и случайный секрет в окружении сервера. Применить миграции Flyway с резервной копией базы. В Android указать адрес этого сервера или опубликовать его в настроенном реестре после проверки идентичности сервера.
3. Добавить в `MCP_REDIRECT_URIS` точный OAuth callback из OpenAI Platform. Сервер рекламирует `iss` и поддерживает S256 и `client_secret_post`. Для подключения этой версии нужен аккаунт Habit Tracker с паролем. Вход Google/Яндекс без пароля пока не поддерживается на странице согласия плагина.
4. Собрать пакет командой `./scripts/Build-ChatGPT-Plugin.ps1 -Server $origin -DeveloperName $publisher -Website $product -Support $support -PrivacyPolicy $privacy -Terms $terms`. Использовать реальные ссылки и имя подтверждённого разработчика. Скрипт добавляет `/mcp` к адресу сервера и выпускает ZIP с иконкой, метаданными и восемью сценариями. Секрет OAuth вводится в кабинете OpenAI, в ZIP его нет.
5. В [кабинете публикации](https://platform.openai.com/apps-manage) загрузить ZIP в разделе Plugins. Значение `OPENAI_APPS_CHALLENGE` устанавливается по подсказке кабинета; backend возвращает его как обычный текст на `/.well-known/openai-apps-challenge`. После проверки домена связать изолированный демо-аккаунт, выполнить сканирование и заполнить требования к демонстрации и проверке. [Процесс публикации](https://developers.openai.com/plugins/deploy/submission).

В настройках ChatGPT выбрать Habit Tracker и разрешить подключение к тому же аккаунту, что используется в Android. На телефоне в поддерживаемом режиме ChatGPT открыть новый чат, выбрать плагин и попросить: «Добавь в Habit Tracker задачу оплатить интернет». Проверить появление задачи, затем повторить проверку со вторым аккаунтом и убедиться, что он её не видит. Доступность конкретного мобильного режима и тарифа следует проверить после публикации.

Локальная проверка backend: `gradle :backend:test :shared:test`. Сценарий публичного режима использует новый аккаунт, OAuth с PKCE, создание задачи через MCP и чтение через тот же `/api/v1/sync`, что использует Android. Он также проверяет изоляцию аккаунтов, привязку токена к клиенту и адресу, и запрет использования токена плагина в REST.
