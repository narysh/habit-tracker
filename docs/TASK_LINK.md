# Задачи и заметки из мобильного ChatGPT

Приложение ChatGPT для Android не подключает пользовательские MCP-серверы. Самый короткий доступный поток — попросить ChatGPT сформулировать задачу или заметку, затем выбрать в меню Android **Поделиться → Habit Tracker**. Приложение сразу сохраняет отправленный текст локально и синхронизирует его при сети. Оно не читает переписку в фоне; запись создаётся только после явной отправки в Habit Tracker.

Добавь в **Настройки → Настроить ChatGPT → Пользовательские инструкции** такой текст. Его можно также отправить в нужный чат. [Инструкция OpenAI](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions).

> Когда я прошу добавить задачу в Habit Tracker, ответь коротким текстом, начинающимся с «Задача:». Используй только названные мной сведения и не придумывай сроки. Для заметки ответь «Заметка: Заголовок», а её текст помести со следующей строки. Для привычки ответь «Привычка: Название», затем укажи ровно один вариант расписания: «Дни: вторник, четверг» или «Цель: 3 дня в неделю». Используй только названные мной дни или цель; если расписание неясно, сначала задай вопрос. Не добавляй вступление и Markdown. Не утверждай, что запись уже сохранена: она появится после отправки ответа через «Поделиться → Habit Tracker».

Приложение распознаёт префикс «Задача:» и простые сроки вроде «завтра в 18:30». Для привычки укажи расписание точной строкой `Дни:` с полными русскими названиями дней недели либо `Цель:` с числом дней за неделю. Если срок задачи неоднозначен или расписание привычки не распознано, откроется редактор для проверки. Остальной отправленный текст сохраняется как заметка. Открытие ссылки задачи или заметки в Android тоже создаёт запись сразу.

Поделиться можно только выбранным ответом, а не автоматически всем чатом. После импорта Habit Tracker перейдёт в соответствующий раздел. Синхронизация продолжится в фоне.
