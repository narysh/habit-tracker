# Задачи и заметки из мобильного ChatGPT

Приложение ChatGPT для Android не подключает пользовательские MCP-серверы. Самый короткий поток — попросить ChatGPT вернуть Markdown-ссылку **«Добавить в Habit Tracker»**, затем нажать её. На устройстве с установленным приложением Android откроет Habit Tracker, где запись сохранится локально и синхронизируется при сети. Приложение не читает переписку в фоне; запись создаётся только после нажатия ссылки.

Добавь в **Настройки → Настроить ChatGPT → Пользовательские инструкции** такой текст. Его можно также отправить в нужный чат. [Инструкция OpenAI](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions).

> Когда я прошу создать задачу, заметку или привычку в Habit Tracker, ответь одной Markdown-ссылкой с текстом «Добавить в Habit Tracker». Для задачи используй адрес habittracker://import/task?title=...&description=...&date=ГГГГ-ММ-ДД&time=ЧЧ%3AММ; добавляй необязательные параметры только если я дал эти сведения. Для заметки используй habittracker://import/note?title=...&text=.... Для привычки используй habittracker://import/habit?title=...&description=...&days=2%2C4 для выбранных дней или &target=3 для недельной цели; дни нумеруются с понедельника: 1–7. Кодируй значения параметров URL-кодированием. Не придумывай сроки, текст или расписание. Если для привычки не хватает расписания — сначала задай вопрос. Не утверждай, что запись уже сохранена: она появится, когда я нажму ссылку.

Приложение распознаёт префикс «Задача:» и простые сроки вроде «завтра в 18:30». Для привычки укажи расписание точной строкой `Дни:` с полными русскими названиями дней недели либо `Цель:` с числом дней за неделю. Если срок задачи неоднозначен или расписание привычки не распознано, откроется редактор для проверки. Остальной отправленный текст сохраняется как заметка. Открытие ссылки задачи или заметки в Android тоже создаёт запись сразу.

Пример для привычки: `[Добавить в Habit Tracker](habittracker://import/habit?title=%D0%91%D0%B5%D0%B3&days=2%2C4)`. Если ChatGPT не открывает ссылку, отправь выбранный ответ через Android-меню **Поделиться → Habit Tracker**. Поделиться можно только выбранным ответом, а не автоматически всем чатом. После импорта Habit Tracker перейдёт в соответствующий раздел. Синхронизация продолжится в фоне.
