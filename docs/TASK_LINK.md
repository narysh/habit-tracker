# Задачи из обычного чата ChatGPT

Прямая интеграция с MCP требует публикации плагина. Пока можно получать редактируемый черновик по ссылке из обычного чата. Установи [APK с импортом задач](https://github.com/narysh/habit-tracker/releases/tag/v0.5.0-preview.1).

В мобильном ChatGPT открой **Настройки → Настроить ChatGPT → Пользовательские инструкции** и добавь этот текст к своим инструкциям. Его можно также отправить прямо в нужный чат. [Инструкция OpenAI](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions).

> Когда я прошу поставить задачу, добавь в ответ Markdown-ссылку `[Открыть задачу в Habit Tracker](https://narysh.github.io/habit-tracker/task/#title=...)`. Передай поля во фрагменте после `#`: `title` (обязательно), `description` (необязательно), `date` в формате YYYY-MM-DD, `time` в формате HH:MM только вместе с датой. Закодируй каждое значение по правилам URL (UTF-8 percent encoding), соединяя поля знаком `&`. Укажи дату и время, только если я их назвал или мы их уточнили. Если я прошу одну задачу, дай одну ссылку. Пиши, что задача станет сохранённой после подтверждения в приложении.

Пример запроса: «Поставь задачу оплатить интернет завтра в 18:00». Нажми ссылку, затем **Открыть в Habit Tracker**. В приложении появится редактор с заполненными полями. Нажми **Сохранить**. Если браузер не открывает приложение, отправь через системное **Поделиться** саму ссылку в Habit Tracker.

Ссылка несёт только текст и срок. Эти поля находятся после `#`, поэтому браузер не отправляет их GitHub Pages. Ссылка остаётся в чате и может сохраняться в истории браузера. Запись создаётся в выбранном Android-аккаунте только после сохранения. Внешние приложения с обработкой ссылки не получают доступа к этому аккаунту.
