# Запись из мобильного ChatGPT

Пользовательские MCP-серверы в ChatGPT подключаются через веб-интерфейс, а не мобильное приложение. На телефоне самый понятный путь — нажать у ответа ChatGPT **Поделиться → Habit Tracker**. Это явное действие: приложение получает только выбранный ответ, а не читает переписку в фоне. [Текущие ограничения MCP в ChatGPT](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt).

Пригласи ChatGPT подготовить блок такого вида, затем поделись ответом:

- Задача: `Задача: Позвонить врачу завтра в 18:30` и описание следующей строкой.
- Заметка: `Заметка: Идея` и текст заметки следующими строками.
- Привычка: `Привычка: Бег`, затем `Дни: вторник, четверг` или `Цель: 3 дня в неделю`.

В **Настройки → Настроить ChatGPT** можно скопировать инструкцию, чтобы ChatGPT придерживался этого формата. Выбери ответ через системное меню Android **Поделиться** и укажи Habit Tracker. Однозначная задача или заметка сохраняется сразу; если срок либо график нельзя надёжно разобрать, приложение откроет проверку. Неоднозначный текст и файлы не теряются: они попадут во входящие черновики.

Ссылки **«Добавить в Habit Tracker»** — необязательный запасной вариант. Если открыть такую ссылку, она создаст запись после явного нажатия. Файл `assetlinks.json` на GitHub Pages нужен только для того, чтобы Android мог сразу открыть подтверждённую ссылку в приложении; он не подключает MCP и не отправляет ответы сам.
