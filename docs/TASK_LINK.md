# Задачи и заметки из обычного чата ChatGPT

В приложении ChatGPT для Android собственный MCP пока недоступен. Вместо ручного копирования можно один раз добавить инструкции ниже: ChatGPT будет давать ссылку на черновик задачи или заметки. Установи [APK с импортом черновиков](https://github.com/narysh/habit-tracker/releases/tag/v0.5.0-preview.1).

В мобильном ChatGPT открой **Настройки → Настроить ChatGPT → Пользовательские инструкции** и добавь этот текст к своим инструкциям. Его можно также отправить прямо в нужный чат. [Инструкция OpenAI](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions).

> Когда я прошу поставить задачу, добавь в ответ Markdown-ссылку `[Открыть задачу в Habit Tracker](https://narysh.github.io/habit-tracker/task/#title=...)`. Передай поля во фрагменте после `#`: `title` (обязательно), `description` (необязательно), `date` в формате YYYY-MM-DD, `time` в формате HH:MM только вместе с датой. Если прошу сохранить заметку или мысль, добавь ссылку `[Открыть заметку в Habit Tracker](https://narysh.github.io/habit-tracker/task/#kind=note&title=...&text=...)`; в `text` передай полный текст заметки. Кодируй значения по правилам URL (UTF-8 percent encoding), соединяя поля знаком `&`. Не придумывай сроки. Если я прошу одну запись, дай одну ссылку. Объясняй, что запись будет создана только после моего подтверждения в приложении.

Для задачи: «Поставь задачу оплатить интернет завтра в 18:00». Для заметки: «Сохрани заметку: идея для проекта — …». Нажми появившуюся ссылку, затем **Открыть в Habit Tracker**. В приложении откроется редактор с заполненными полями; проверь их и нажми **Сохранить**. Приложение не читает другие чаты и ничего не создаёт без этого подтверждения. Если браузер не открывает приложение, отправь через системное **Поделиться** саму ссылку в Habit Tracker.

Ссылка несёт только текст и срок. Эти поля находятся после `#`, поэтому браузер не отправляет их GitHub Pages. Ссылка остаётся в чате и может сохраняться в истории браузера. Запись создаётся в выбранном Android-аккаунте только после сохранения. Внешние приложения с обработкой ссылки не получают доступа к этому аккаунту.
