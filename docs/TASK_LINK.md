# Задачи и заметки из мобильного ChatGPT

Приложение ChatGPT для Android не подключает пользовательские MCP-серверы. Самый короткий доступный поток — попросить ChatGPT сформулировать задачу или заметку, затем выбрать в меню Android **Поделиться → Habit Tracker**. Приложение сразу сохраняет отправленный текст локально и синхронизирует его при сети. Оно не читает переписку в фоне; запись создаётся только после явной отправки в Habit Tracker.

Добавь в **Настройки → Настроить ChatGPT → Пользовательские инструкции** такой текст. Его можно также отправить в нужный чат. [Инструкция OpenAI](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions).

> Когда я прошу добавить задачу в Habit Tracker, ответь коротким текстом, начинающимся с «Задача:». Используй только названные мной сведения. Если я назвал срок, оставь его в тексте, например «Задача: Позвонить врачу завтра в 18:30». Когда я прошу сохранить заметку, ответь «Заметка: Заголовок», а текст заметки помести со следующей строки. Не добавляй вступление, Markdown и выдуманные сроки. Не утверждай, что задача уже сохранена: она появится в приложении после того, как я отправлю твой ответ через «Поделиться → Habit Tracker».

Приложение распознаёт префикс «Задача:» и простые сроки вроде «завтра в 18:30». Если формулировка даты неоднозначна, откроется проверка задачи. Остальной отправленный текст сохраняется как заметка. Открытие ссылки задачи или заметки в Android тоже создаёт запись сразу.

Поделиться можно только выбранным ответом, а не автоматически всем чатом. После импорта Habit Tracker перейдёт в раздел задач или заметок. Синхронизация продолжится в фоне.
