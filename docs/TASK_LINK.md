# Задачи и заметки из мобильного ChatGPT

Приложение ChatGPT для Android не подключает пользовательские MCP-серверы. Самый короткий поток — попросить ChatGPT вернуть HTTPS-ссылку **«Добавить в Habit Tracker»**, затем нажать её. Если Android подтвердил связь приложения с `narysh.github.io`, откроется Habit Tracker и запись сохранится локально. Если проверка ещё не завершилась или клиент открыл страницу в браузере, нажми **«Открыть в Habit Tracker»**. Приложение не читает переписку в фоне; запись создаётся только после нажатия ссылки.

Добавь в **Настройки → Настроить ChatGPT → Пользовательские инструкции** такой текст. Его можно также отправить в нужный чат. [Инструкция OpenAI](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions).

> Когда я прошу добавить задачу, заметку или привычку в Habit Tracker, ответь одной Markdown-ссылкой «Добавить в Habit Tracker» на `https://narysh.github.io/habit-tracker/task/#...`. Для задачи используй параметры `kind=task&title=...&description=...&date=ГГГГ-ММ-ДД&time=ЧЧ%3AММ`; указывай необязательные поля только если я дал эти сведения. Для заметки используй `kind=note&title=...&text=...`. Для привычки используй `kind=habit&title=...&description=...&days=2%2C4` для выбранных дней либо `&target=3` для недельной цели; дни нумеруются с понедельника: 1–7. Кодируй значения URL-кодированием. Не придумывай сроки, текст или расписание. Если не хватает названия либо расписания привычки — сначала задай вопрос. Не утверждай, что запись уже сохранена: она появится после нажатия ссылки и открытия Habit Tracker.

Приложение распознаёт префикс «Задача:» и простые сроки вроде «завтра в 18:30». Для привычки укажи расписание точной строкой `Дни:` с полными русскими названиями дней недели либо `Цель:` с числом дней за неделю. Если срок задачи неоднозначен или расписание привычки не распознано, откроется редактор для проверки. Остальной отправленный текст сохраняется как заметка. Открытие ссылки задачи или заметки в Android тоже создаёт запись сразу.

Пример для привычки: `[Добавить в Habit Tracker](https://narysh.github.io/habit-tracker/task/#kind=habit&title=%D0%91%D0%B5%D0%B3&days=2%2C4)`. Если ChatGPT не открывает ссылку, отправь выбранный ответ через Android-меню **Поделиться → Habit Tracker**. Поделиться можно только выбранным ответом, а не автоматически всем чатом. После импорта Habit Tracker перейдёт в соответствующий раздел. Синхронизация продолжится в фоне.
